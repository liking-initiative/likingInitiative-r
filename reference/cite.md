# Citation text

Please cite both the database and the study whose data you used.

## Usage

``` r
cite(x, ...)
```

## Arguments

- x:

  A dataset or item from
  [`get_dataset()`](https://liking-initiative.github.io/likingInitiative-r/reference/get_dataset.md)
  /
  [`get_item()`](https://liking-initiative.github.io/likingInitiative-r/reference/get_item.md).
  With no argument, returns the citation for the database itself.

- ...:

  Unused.

## Value

A character string.

## Examples

``` r
cite()
#> [1] "Fernandez, K., Goyal, S., & Krajbich, I. (2026). The Liking Initiative: a database of subjective evaluation ratings for decision-making research [Data set]. Zenodo. https://doi.org/10.5281/zenodo.22216442"
```
